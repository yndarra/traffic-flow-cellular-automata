Микроскопическое моделирование движения машин на кольцевой дороге двумя
стохастическими клеточными автоматами:

* **Нагеля–Шрекенберга (NaSch)** со *смешанным потоком*: часть машин ведут
  люди, которые случайно притормаживают, остальные — автопилот, который едет
  детерминированно;
* **S-NFS** — стохастическое обобщение модели Нисинари–Фукуи–Шадшнайдера
  (Sakai, Nishinari, Iida, 2006). В нём есть *медленный старт* и *упреждение*:
  водитель учитывает машину через одну впереди.

В проекте строятся фундаментальные диаграммы (поток от плотности),
пространственно-временные диаграммы и распределения скоростей. Отдельно
измеряется, насколько доля водителей-людей снижает пропускную способность
дороги.

## Модели

Дорога — кольцо из `L` клеток, в каждой не больше одной машины. Скорость — целое
число от `0` до `v_max` клеток за шаг. Все машины обновляются параллельно.
Обгонов нет, поэтому лидер у каждой машины не меняется, и шаг векторизуется
сразу по всем машинам.

### NaSch со смешанным потоком

1. **Ускорение:** `v ← min(v + 1, v_max)`
2. **Торможение:** `v ← min(v, gap)`, где `gap` — число свободных клеток до лидера
3. **Случайное торможение:** `v ← max(v − 1, 0)` с вероятностью `p_slow`, **только у водителей-людей**
4. **Движение:** `x ← x + v`

`RHDV` (ratio of human-driven vehicles) — доля машин, которые случайно тормозят.
`RHDV = 1` — классическая модель NaSch, `RHDV = 0` — полностью
детерминированный поток беспилотных машин.

### S-NFS

1. **Ускорение:** `v ← min(v + 1, v_max)`
2. **Медленный старт** (с вероятностью `q`): водитель реагирует на дистанцию
   *прошлого* шага, `v ← min(v, x'ᵢ₊₁ − x'ᵢ − 1)`
3. **Упреждение** (quick start): с вероятностью `r` водитель смотрит на `S = 2`
   машины вперёд, иначе `S = 1`: `v ← min(v, xᵢ₊ₛ − xᵢ − S)`
4. **Случайное торможение** с вероятностью `p_brake` (в статье это `1 − p`)
5. **Без столкновений:** `v ← min(v, gap + v_лидера)`
6. **Движение:** `x ← x + v`

## Результаты

### NaSch: водители-люди ограничивают пропускную способность

Параметры: `v_max = 5`, `p_slow = 0.8`, кольцо из 1000 клеток. Каждая точка
усреднена по 500 шагам после разгона в 2000 шагов, а затем по 3 независимым
начальным расстановкам.

![Фундаментальные диаграммы NaSch](images/nasch_fundamental.png)

| RHDV | Максимальный поток, машин/шаг | при плотности |
|---|---|---|
| 0 (все беспилотные) | **0.830** | 0.17 |
| 0.3 | 0.374 | 0.09 |
| 0.7 | 0.199 | 0.05 |
| 1 (все люди) | 0.144 | 0.04 |

Беспилотный поток выходит ровно на теоретический оптимум
`J_max = v_max / (v_max + 1) = 5/6` при `ρ = 1/(v_max + 1)`. Уже 30%
водителей-людей снижают пропускную способность больше чем вдвое: каждая такая
машина становится медленным лидером колонны.

### Пространственно-временные диаграммы

Время идёт вниз, машины едут вправо. Красные полосы — пробки, которые сползают
*назад*, против движения.

![x–t диаграммы](images/nasch_space_time.png)

При плотности 0.3 беспилотные машины едут со средней скоростью 2.33 клетки за
шаг, стоят 10.7% машин. При 70% водителей-людей средняя скорость падает до
0.48, а в пробках стоят 73.6% машин.

![Распределение скоростей](images/nasch_velocities.png)

### S-NFS: медленный старт против упреждения

Параметры: `v_max = 3`, `p_brake = 0.1`.

![Фундаментальные диаграммы S-NFS](images/snfs_fundamental.png)

| q | r | Максимальный поток | при плотности |
|---|---|---|---|
| 1 | 0.5 | 0.394 | 0.15 |
| 1 | 1 | 0.385 | 0.16 |
| 0 | 0 | 0.586 | 0.25 |
| 0 | 1 | **0.921** | 0.36 |

При постоянном медленном старте (`q = 1`) упреждение почти ни на что не
влияет: машина, стоящая в пробке, в любом случае ждёт лишний шаг. Без
медленного старта упреждение позволяет машинам ехать очень плотно. Пропускная
способность растёт почти на 60% (0.921 против 0.586), а пик смещается к
гораздо большей плотности.

## Запуск

```bash
git clone https://github.com/yndarra/traffic-flow-cellular-automata.git
cd traffic-flow-cellular-automata
python -m venv .venv
.venv/Scripts/activate        # Windows; в Linux/macOS: source .venv/bin/activate
pip install -r requirements.txt

python main.py                # все эксперименты (около 2 минут), картинки — в images/
python main.py nasch          # один эксперимент: nasch | xt | snfs | ring
```

Тесты:

```bash
pip install -r requirements-dev.txt
pytest
```

Тесты проверяют, что машины не сталкиваются и не обгоняют друг друга, что их
число сохраняется, а детерминированная модель NaSch воспроизводит
аналитический поток `min(ρ·v_max, 1 − ρ)`.
